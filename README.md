\# Muramba Transport Management System



\## Project Description



The Muramba Transport Management System is a proposed digital

solution developed for Muramba Enterprise Solutions.



The system is designed to improve the management of customers,

transport bookings, deliveries, invoices and reports.



\## Services



\- Furniture removals

\- Goods delivery

\- Moving services



\## System Features



\- Customer registration

\- Customer login

\- Booking management

\- Delivery tracking

\- Invoice management

\- Reports

\- Customer information management



\## Technologies Used



\- HTML

\- CSS

\- JavaScript



\## Project Structure



\- index.html - Homepage

\- css - Website styling

\- js - JavaScript functionality

\- images - Website images

\- pages - Additional website pages

\## Purpose



The purpose of the system is to reduce manual record keeping,

improve booking management, improve delivery tracking and provide

better customer service.
